# 📦 Supply Chain Demand Forecasting AI System

Multi-model forecasting system using:
- XGBoost
- LSTM
- ARIMA
- Temporal Fusion Transformer (TFT)

## Features
- FastAPI backend
- Streamlit luxury dashboard
- Real-time SKU prediction
- Multi-model AI engine

## Run Backend
uvicorn api:app --reload

## Run Dashboard
streamlit run dashboard/app.py
